# C++

这里不是一个统一编译的 C++ monorepo，而是多个可以独立生长的小项目的集合。分类目录只帮助 VS Code 导航，不提供跨项目依赖。

## 分类

- `00_scratch/`：快速验证想法，允许没有 README，验证完成后删除或提升。
- `10_learning/`：学习主题，每个子目录是一个独立项目。
- `20_libraries/`：真正会复制到多个项目里的小型库，优先单头文件、零依赖。
- `30_projects/`：较完整的应用、工具或长期实验。
- `_template/`：新项目模板，不直接开发。

## 一个项目的最低标准

```text
project/
├── README.md       # 目标、依赖、构建、运行、已知问题
├── CMakeLists.txt  # 或项目自带的 build.* / nob.cpp
└── main.cpp        # 小项目可以保持扁平；变大后再引入 src/include
```

不要为了“看起来统一”给所有项目强行加入公共框架。项目自身的构建方式就是项目的一部分。
